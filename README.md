## About the Project

When someone goes to buy a laptop they get overwhelmed by specs — RAM, CPU generation, GPU model, storage type. This project solves that. You input the hardware specs of any laptop and the model tells you instantly which tier it belongs to:

| Tier | What it means |
|------|--------------|
| 🔵 **Basic** | Entry-level — good for browsing, documents, light tasks |
| 🟡 **Mainstream** | Mid-range — suitable for most everyday and professional work |
| 🟢 **Powerhouse** | High-end — gaming, video editing, data science, heavy workloads |

The model achieves **~99% test accuracy** and **~99.8% cross-validation accuracy**.

---

## How It Works

```
Raw CSV (messy text specs)
        ↓
Feature Engineering (17 features extracted)
        ↓
Label Generation via SpecScore (qcut into 3 tiers)
        ↓
XGBoost + Random Forest → Soft Voting Ensemble
        ↓
Tier Prediction + Probability Scores
```

1. The raw dataset has specs as free-text strings (e.g. `"512GB NVMe SSD"`, `"Intel Core i7"`)
2. The `engineer_features()` function parses and converts them into numeric/categorical features
3. A composite `SpecScore` is computed and quantile-cut into 3 equal tiers (Basic / Mainstream / Powerhouse)
4. The ensemble model is trained on 80% of the data and evaluated on the remaining 20%
5. The Streamlit app lets you input any laptop config and get a real-time prediction

## Getting Started

### Prerequisites

- Python 3.9 or higher
- pip

### Installation

**1. Clone the repository**
```bash
git clone https://github.com/Krishnathaker78/LAPTOP_SYSTEM_CLASSIFICATION.git
cd LAPTOP_SYSTEM_CLASSIFICATION
```

**2. Create a virtual environment (recommended)**
```bash
python -m venv venv

# On Windows
venv\Scripts\activate

# On macOS/Linux
source venv/bin/activate
```

**3. Install dependencies**
```bash
pip install -r requirements.txt
```

**4. Add the dataset**

Place your `laptops.csv` file in the `data/` folder.
If you don't have it, download it from the [Hugging Face Space files](https://huggingface.co/spaces/Krishnathaker78/LAPTOP_SYSTEM_CLASSIFICATION/blob/main/laptops.csv).

### Running the App

```bash
streamlit run app.py
```

The app will open automatically in your browser at `http://localhost:8501`

### Training the Model Standalone

If you just want to train and save the model without the UI:

```bash
python train.py
```

This will save the trained model to `model/final_model.pkl` and print accuracy metrics.

## Model Details

### Architecture: Soft-Voting Ensemble

The final classifier combines two models:

**XGBoost Classifier**
```python
XGBClassifier(
    n_estimators=300,
    learning_rate=0.10,
    max_depth=6,
    subsample=0.85,
    colsample_bytree=0.80,
    min_child_weight=2,
    gamma=0.05,
    reg_alpha=0.1,
    reg_lambda=1.2,
    eval_metric='mlogloss'
)
```

**Random Forest Classifier**
```python
RandomForestClassifier(
    n_estimators=200,
    max_depth=10,
    min_samples_split=4,
    min_samples_leaf=2,
    n_jobs=-1
)
```

**Ensemble**
```python
VotingClassifier(
    estimators=[('xgb', xgb_clf), ('rf', rf_clf)],
    voting='soft'
)
```

### Why This Ensemble?

- **XGBoost** corrects errors sequentially (boosting) — great for capturing complex patterns
- **Random Forest** averages independent trees (bagging) — reduces variance
- Their errors are uncorrelated so combining them gives better results than either alone
- Both handle mixed feature types (ordinal, binary, one-hot) without scaling

## Feature Engineering

All 17 features are engineered from raw text columns:

| Feature | Type | Description |
|---------|------|-------------|
| `Ram_GB` | Integer | Extracted from RAM string e.g. "16GB" → 16 |
| `Storage_GB` | Integer | Parsed from storage string, TB converted to GB |
| `StorageType` | Categorical | NVMe / SSD / HDD / SSHD / Fusion / Flash |
| `StorageSpeed` | Ordinal 1–4 | NVMe=4, SSD=3, Fusion=2, HDD=1 |
| `CPU_Tier` | Ordinal 0–3 | Atom=0, i3=1, i5=2, i7/Xeon=3 |
| `CPU_Brand` | Categorical | Intel or AMD |
| `GPU_Tier` | Ordinal 0–2 | Integrated=0, GTX 1650=1, RX 5600M=2 |
| `GPU_Brand` | Categorical | Nvidia / AMD / Intel |
| `Is_Touchscreen` | Binary | 1 if touchscreen |
| `Is_IPS` | Binary | 1 if IPS panel |
| `Is_4K` | Binary | 1 if 4K resolution |
| `Is_2K` | Binary | 1 if 2K resolution |
| `Is_Retina` | Binary | 1 if Retina display (Apple) |
| `IsPremiumBrand` | Binary | 1 for Apple / Microsoft / Dell |
| `IsGaming` / `IsWorkstation` / `IsConvertible` / `IsUltrabook` | Binary x4 | Form factor flags |
| `PowerScore` | Float | `RAM × (CPU_Tier+1) × GPU_Tier_Score` |
| `SpecScore` | Float | Used only for label generation via qcut |

**Label Generation:**
```python
df['SpecTier'] = pd.qcut(
    df['SpecScore'], q=3,
    labels=['Basic', 'Mainstream', 'Powerhouse'],
    duplicates='drop'
)
```

## Dataset

The `laptops.csv` dataset contains real laptop product listings with raw specification strings as they appear in retail catalogs.

**Key columns:**
- `CompanyName` — Brand (Dell, Apple, MSI, Asus, etc.)
- `TypeOfLaptop` — Form factor (Gaming, UltraBook, WorkStation, etc.)
- `Cpu` — CPU description string
- `Ram` — RAM string (e.g. "16GB")
- `Memory` — Storage string (e.g. "512GB NVMe SSD + 1TB HDD")
- `Gpu` — GPU name
- `ScreenResolution` — Resolution free-text string
- `OpSys` — Operating system
- `Weight` — Weight string

**Download:** [laptops.csv on Hugging Face](https://huggingface.co/spaces/Krishnathaker78/LAPTOP_SYSTEM_CLASSIFICATION/blob/main/laptops.csv)

## Known Limitations

- **Label leakage** — SpecScore (target basis) is correlated with PowerScore (training feature). Inflates accuracy.
- **Narrow GPU taxonomy** — Only 3 GPU tiers recognized. Modern GPUs (RTX 4060, 4090, Apple M-series) fall back to Integrated.
- **CPU taxonomy gaps** — No AMD Ryzen or Apple Silicon support. No within-generation differentiation.
- **Static dataset** — No live data updates. Model becomes outdated as new laptops are released.
- **Pickle serialization** — `final_model.pkl` uses Python pickle which has security risks in production.
